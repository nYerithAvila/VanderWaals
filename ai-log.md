# DECLARATORIA DE USO DE IA PARA EL EQUIPO VANDERWAALS 
## Filosofia de uso 
Al ser principiantes en el mundo de la programación usamos la IA para explicaciones generales, correccion de codigo y detalles relacionados a la programación. No usamos IA para definir la problematica o el ritmo de nuestra historia. 
Nuestra frase es: 
> ChatGPT no puede preocuparse como nosotros por el agua. Es nuestra responsabilidad darle un enfoque único a nuestro tablero y plasmar nuestras preocupaciones por el ODS6.


## Uso de IA en el equipo VanderWaals

| IA | Tarea delegada | Ejemplo de prompt | Resultado obtenido | Decisión y justificación | Modificaciones del equipo |
|----|--------------|------------------|-------------------|--------------------------|---------------------------|
| ChatGPT | Detección de errores | “Estoy programando con python por medio de jupyter notebook, usando pandas para análisis de datos y me marca el siguiente error [...], ayúdame a detectar en qué estoy fallando.” | Serie de indicaciones para resolver errores (muchas veces detalles simples como comas o sintaxis ☹️). | Al ser principiantes en programación, intentamos resolver errores primero con base en capacitaciones; cuando no fue posible, recurrimos a la IA como apoyo. | Adaptamos soluciones generales (ej. uso de “pip”) a nuestro entorno específico (“uv”). |
| ChatGPT | Explicación de líneas de código | “Explícame esta función de mi código [...]” | Explicación del funcionamiento y propósito de código tomado de herramientas como Quarto o Plotly. | Comprender el código permite usar menos la IA y tomar mejores decisiones al modificar nuestro codigo. | No se realizaron modificaciones, se utilizó como apoyo para comprensión. |
| Claude AI | Ideas de mejora para el código | “Tengo este código funcional para una visualización de datos, ¿qué mejoras podría hacer para un mejor resultado?” | Código optimizado con mejoras en visualización y estructura. | Se utilizó como complemento para elevar la calidad visual, partiendo de bases aprendidas en las capacitaciones. | Se seleccionaron solo las recomendaciones alineadas a los requisitos del hackathon. |
| ChatGPT | Mejora del README | “Tengo este texto al cual quiero darle formato tabla en markdown, transcribirlo sin modificar el contenido.” | Un markdown más estético. | Ahorrar tiempo y reducir errores en la escritura manual del README. | Ajustes menores para personalizar formato y presentación. |

## ¿Y la Inteligencia Natural? 

- No usamos IA para decidir el rumbo de nuestra historia ni elegir el ODS, esta elección viene directamente de nuestras motivaciones personales y de tratar el tema a traves de varias reuniones virtuales. 

- Tampoco usamos IA para definir las partes de nuestro storytelling, pues creemos que es la parte medular del proyecto y debe de tener la escencia de nuestro equipo.

- No usamos IA para redactar documentos como el readme o la declaratoria de IA, si a caso solo para corregir algunos errores gramaticales o de puntuación.
